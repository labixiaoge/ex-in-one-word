## About

A one-word verdict on an ex, written for [make.fun](https://make.fun)'s "Describe Your Ex in One Word" bounty.

The entry program (`main.ts`) writes the word to `/output/entry.txt`:

> Clearance

The ex as clearance-rack stock: marked down, picked over, and nobody wanted them at full price. One word, instantly a verdict, and the joke lands at a glance.

## Run

```sh
node main.ts
```

Deterministic, no network: it always writes the same 9-character word to `/output/entry.txt`.
